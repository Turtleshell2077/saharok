# СахарОК — личный помощник при диабете 1 типа

Веб-приложение (PWA): ставится на телефон как обычное приложение, работает без интернета,
а с онлайн-сохранением хранит данные в облаке и подписывает календарь телефона на дела и напоминания.

> Это помощник, а не медицинское изделие. Расчёт дозы опирается на коэффициенты,
> которые вводит пользователь. Их подбирает эндокринолог.

## Что умеет

| Раздел | Что внутри |
|---|---|
| **Главная** | последний сахар и тренд, быстрый ввод замера одной строкой, активный инсулин, ночной инсулин на эту ночь, график дня, питание, дела на сегодня, режим, цикл, записки поддержки |
| **Дневник** | лента дней, сводка дня (сахар, ХЕ, калории, инсулин), график, понятные записи; добавление по типам: сахар, еда, укол, заметка |
| **Доза** | поиск продуктов прямо в калькуляторе, недавние продукты и свои блюда в одно касание, расчёт «еда + коррекция − активный инсулин», учёт тренда сахара, недавней гипо, нагрузки, цикла и меток; **поправка по её истории** |
| **Планы** | ежедневник: дела по датам (просрочено → сегодня → завтра → дальше → без даты), категории, время, «важное», экспорт в календарь; режим дня, который она составляет сама; настраиваемые запасы |
| **Ночной инсулин** | один укол в сутки, защита от двойного укола, доза на эту ночь с учётом прошлых ночей и сегодняшней нагрузки |
| **Питание** | норма калорий по формуле Миффлина — Сан Жеора, БЖУ, ХЕ в день и по приёмам пищи, учёт за день и неделю |
| **Ещё** | анализ, продукты (166 шт. с калориями и БЖУ), места уколов, отчёт для врача, справочник, достижения, онлайн-сохранение, настройки |

### Как расчёт учитывает её историю
За последние 4 недели приложение сравнивает сахар до еды и через 2,5–5 часов после неё
(без нагрузки, болезни, алкоголя и жирной еды). Если после завтраков сахар стабильно растёт,
доза на завтрак чуть увеличивается; если после еды бывают гипо — только уменьшается.
Поправка не больше +10% и −20%, нужно минимум 4 приёма пищи в это время суток.
То же для ночного инсулина: рост за ночь → +10%, ночная гипо → −10–20%, нагрузка днём → меньше на ночь.
Всё показывается отдельной строкой в расчёте и выключается в настройках.

## Пошаговая настройка: облако + телефон + календарь

Займёт около 30–40 минут. Всё бесплатно.

### Шаг 1. Облачная база (Supabase)

1. Зайди на [supabase.com](https://supabase.com) → **Start your project** → войди через GitHub или почту.
2. **New project**: имя `saharok`, придумай пароль базы (сохрани его), регион — **Central EU (Frankfurt)**. Подожди 1–2 минуты.
3. Слева **SQL Editor** → **New query** → вставь содержимое файла [`supabase/setup.sql`](supabase/setup.sql) → **Run**. Должно написать `Success`.
4. Слева **Authentication** → **Sign In / Providers**. Вверху страницы, в блоке **User Signups** (не внутри окна «Email»), выключи **Confirm email** → **Save changes**.
   *(Так Аля сможет войти сразу. Если оставить включённым — после регистрации придёт письмо, по ссылке из него нужно подтвердить почту.)*
5. Слева **Project Settings** → **API Keys**. Скопируй:
   - **Project URL** (вида `https://abcd1234.supabase.co`, иногда он на вкладке **Data API**);
   - **Publishable key** (или **anon public** на вкладке Legacy API keys).
6. Открой файл [`js/config.js`](js/config.js) и впиши их:
   ```js
   window.SAHAROK_CONFIG = {
     supabaseUrl: 'https://abcd1234.supabase.co',
     supabaseKey: 'sb_publishable_...',
   };
   ```
   Этот ключ публичный — его можно хранить в коде: правила базы из `setup.sql` разрешают каждому видеть только свою строку.

### Шаг 2. Календарь по ссылке (функция в Supabase)

1. В Supabase слева **Edge Functions** → **Deploy a new function** → **Via Editor**.
2. Имя функции: `calendar`. Сотри пример и вставь всё из [`supabase/functions/calendar/index.ts`](supabase/functions/calendar/index.ts) → **Deploy function**.
3. Открой функцию → **Details** (или **Settings**) → выключи **Verify JWT** / **Enforce JWT verification** → **Save**.
   Это нужно, потому что календарь телефона не умеет передавать ключи. Доступ закрыт секретным токеном в ссылке.

Через командную строку то же самое: `supabase functions deploy calendar --no-verify-jwt`.

### Шаг 3. Выложить приложение (GitHub Pages)

1. Зарегистрируйся на [github.com](https://github.com) → **New repository** → имя `saharok`, **Public** → **Create**.
2. **Add file → Upload files** → перетащи всё содержимое папки `saharok` (папки `css`, `js`, `icons`, `supabase`, файлы `index.html`, `manifest.json`, `sw.js`) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
   Через 1–2 минуты сверху появится адрес: `https://<логин>.github.io/saharok/`.
4. Вернись в Supabase → **Authentication → URL Configuration** → в **Site URL** вставь этот адрес → **Save**.

В репозитории нет личных данных: дневник хранится на телефоне и в её строке в Supabase.

### Шаг 4. На телефоне у Али

1. Открой адрес из шага 3: на **iPhone — в Safari**, на **Android — в Chrome**.
2. Установи на главный экран:
   - iPhone: кнопка «Поделиться» → **На экран «Домой»** → Добавить;
   - Android: меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
3. Дальше открывай только с иконки — так данные не стираются браузером и работают уведомления.
4. Пройди мастер настройки: имя, рост/вес/активность, **сколько граммов в 1 ХЕ**, коэффициенты на утро/день/вечер/ночь и ФЧИ (из выписки эндокринолога), инсулины.
5. **Ещё → Онлайн-сохранение** → почта и пароль → **Создать аккаунт**. На новом телефоне потом — **Войти**, всё подтянется.
6. **Планы → Режим дня → Включить уведомления** → Разрешить. *(На iPhone уведомления работают только у приложения, установленного на экран «Домой», iOS 16.4+.)*

### Шаг 5. Календарь телефона

В приложении: **Ещё → Онлайн-сохранение** → блок «Календарь телефона» → скопируй ссылку.

- **iPhone:** Настройки → Приложения → Календарь → Учётные записи календаря → Добавить учётную запись → Другое → **Добавить подписной календарь** (на iOS 17 и старше: Настройки → Календарь → Учётные записи) → вставь ссылку → Далее → Сохранить. Там же выключи **«Удалить предупреждения»**, чтобы приходили напоминания. Календарь обновляется сам.
- **Android:** на компьютере открой [calendar.google.com](https://calendar.google.com) под тем же аккаунтом, что на телефоне → слева «Другие календари» → «+» → **Добавить по URL** → вставь ссылку. Google обновляет такие календари раз в несколько часов и не всегда присылает по ним уведомления — для точных напоминаний нажми в приложении **«Скачать файл .ics»** и открой его на телефоне: события добавятся в её собственный календарь.

В календарь попадают: дела с датой (с временем — с напоминанием), режим дня, ночной инсулин в его время.

### Шаг 6. Записки от тебя

**Настройки → Записки поддержки**: впиши своё имя в «От кого» и пару тёплых фраз, по одной на строку. Через день они будут появляться на главной вместо обычных подсказок.

## Обновление приложения

Замени файлы в репозитории на GitHub и увеличь номер в первой строке `sw.js` (`saharok-v2` → `saharok-v3`).
На телефоне достаточно закрыть и снова открыть приложение. Данные не теряются.

## Если что-то пошло не так

| Что видно | Что сделать |
|---|---|
| «В базе нет таблицы user_data» | Не выполнен `setup.sql` (шаг 1.3) |
| «Почта не подтверждена» | Открыть письмо от Supabase или выключить Confirm email (шаг 1.4) |
| «Нет связи с сервером» | Проверить интернет; приложение продолжит работать и сохранит всё позже |
| Календарь не открывается по ссылке | Не выключена проверка JWT у функции (шаг 2.3) |
| Проект Supabase «на паузе» | Бесплатные проекты засыпают после недели без запросов — нажать **Restore project** в панели; данные сохраняются |
